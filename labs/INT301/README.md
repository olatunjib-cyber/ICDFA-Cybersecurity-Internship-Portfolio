# 🐧 INT301 – Operating Systems Fundamentals

## 📖 Course Overview

This course introduces the fundamentals of the Linux operating system using the Kali Linux distribution. Through practical laboratory exercises, I developed foundational Linux administration skills, software management, networking, file permissions, Bash scripting, automation, and hands-on Capture The Flag (CTF) challenges.
